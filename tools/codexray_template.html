how to use it

  1. Open CodeXRay. If it is slow the first time, wait a minute while the server starts.
  2. Copy one of the sample programs below and paste it into the Source Code Editor, replacing the code that is there.
  3. Click Run Pipeline, then click each stage to see what it produced.
  4. Click Call Stack & Memory to see the functions and variables while the program runs.

CodeXRay cannot type input for your program, so use programs that do not use scanf(), like the samples below.
